### 承载面选取

`grandma.bake.json` 绑定原 GLB SHA-256，明确选取地面、桥面、石阶、岩石顶面和凉亭底板，单位法线 Y≥0.5。主石阶实际属于 `SM_rocks` 而非 `rock_steps`，两种岩石材质均需选入。`support_height_ranges` 对指定网格限制归一化世界坐标的 Y 高度带，三角形全部角点须在范围内，不裁剪出新表面：桥为 33.50–33.55 m（排除桥栏杆／桥墩底座），凉亭为 15.2–16.1 m（保留底板、排除柱头和屋顶）。不将房顶、树干、其他道具顶部或展台外壳当成承载面。高度带在 `--model-span` 归一化后的坐标中解释，不自动按比例改写。

选取结果单独存入 `.fogscene` 的 `support` 数组；改变分辨率／区域后仍从相同承载面重烘焙，不能回退成所有显示网格。高度场仍是一层：桥下和桥上不能同时承载独立雾层；同一选取集合的重叠取最高面。缺少承载面的格保持无效，不猜测地面。格值是中心点采样，0.25 m 格在边缘和斜坡呈阶梯，不能要求整个格面与斜三角形处处重合。

### 简化碰撞与地面独立

碰撞保留房屋、树干和实心道具，不因其未进入 `support` 而删除；仅按配置排除人工展台外壳。碰撞在同一世界变换下焊接（容差 0.00001 m），使用 meshopt、8,000 面目标、0.025 m 绝对误差预算，锁定开放边界。`lock_collision_extrema` 还锁定焊接连通部件的六个轴向极值，避免细枝末端缩短。对 ≤128 顶点的小部件，检查原顶点到简化三角形的实际距离；超过 0.025 m 时以 1/4、1/16 误差分别重试，再失败才保留该部件原面。本资源细化 433 个小部件，其中 210 个保留原细节。大块地形仍简化；目标不是硬上限，不为凑数量丢失物理特征。meshopt 误差和小部件顶点检查都不是整网格的严格 Hausdorff 上界。

运行时相机只对简化网格构建一次 BVH，叶最多 8 三角形，每帧先筛选相机臂扫掠包围盒。角色仍使用高度场与局部阻挡面，不是完整三角网格刚体角色控制器，未引入物理引擎。陡立碰撞面与局部地面至 1.8 m 高范围重叠时生成共享面阻挡。

显示仍是原不透明几何和基色贴图采样的线性 RGB 顶点色，不是完整 PBR；透明／alpha-mask 树叶、草片、水面、透射和发光扩展仍不导入。

## 几何对照验收

通过外观面板的“几何验收”在同一独立相机下切换实际模型、青色碰撞、橙色原始高度格、红色阻挡边与紫色承载原面，可选穿透叠加。该显示直接使用实际 CPU 碰撞源和原始 Terrain，不读雾的坡度过滤掩码。操作与固定相机快照见 [Fog 指南](../../../doco/guides/fog.md#几何验收)。

固定视角检查包含正面／背面／俯视、桥面及桥墩、主石阶、凉亭与细树枝近景；这些视角未见整体变换错位，桥栏杆不承载、石阶与凉亭底板覆盖正确。独立离线双向点到三角形抽样（每面顶点、三边中点、重心，去重后碰撞侧 204,434 点、原实心几何侧 241,062 点）最大偏差分别约 0.04651／0.04954 m；抽样不是连续表面的上界，不保证所有视角、子像素细节或多层空间匹配。回归检查另固定主石阶、凉亭底板、桥面与细枝的实测世界坐标，防止资源替换后再丢失。

## 资源格式与重烘焙

- `grandma.fogscene`：`FOGSCN03`，8 字节 magic；五个 little-endian u32（显示 floor 数、obstacle 数、颜色标记、碰撞三角数、承载三角数）；随后为 f32 显示三角形、可选逐角 RGB、碰撞三角形、承载三角形。加载检查长度、数量及有限数。兼容读取 `FOGSCN02`，旧格式／手写 JSON 没有 `support` 时沿用全部 floor。
- `grandma.fogterrain`：高度、有效格、通行面与包含承载面在内的完整 BakeSource SHA-256。旧场景配新地形或反之会因来源不符拒绝加载。
- 烘焙配置要求来源 SHA 一致、网格名称存在、至少选出一个向上承载三角形；错误时拒绝输出，不静默回退所有网格。

输出必须不存在。先生成新文件，再显式替换发布资产：

```powershell
cargo run --release -p swe-fog -- --import-glb assets/models/dae_diorama_-_grandmas_house.glb --bake-profile crates/swe-fog/assets/grandma.bake.json --bake-scene grandma-new.fogscene --bake grandma-new.fogterrain --model-span 64 --resolution 256
cargo run --release -p swe-fog -- --scene grandma-new.fogscene --terrain grandma-new.fogterrain --no-settings
```

不指定 `--bake-profile` 的通用 GLB 导入仍保留旧的全部不透明面取高语义，不应据此覆盖 Grandma 正式资源。可用 `--scene grandma.fogscene --bake new.fogterrain` 重烘焙，已打包的承载面会保留。
