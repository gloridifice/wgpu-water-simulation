# 工作区图标

GPU Ocean 五分类导航的 SVG 候选资源，尚未接入 egui；视觉风格待预览确认。

| 文件 | 分类 | 图形 |
| --- | --- | --- |
| `scene.svg` | 场景 | 等轴空间方块 |
| `shallow.svg` | 浅水 | 水面与近岸坡底截面 |
| `offshore.svg` | 远海 | 单个卷浪 |
| `shading.svg` | 着色 | 半明半暗球体与光源 |
| `configurations.svg` | 配置 | 带调节项的参数卡片 |

全部使用 `viewBox="0 0 24 24"`、1.75 单位圆端描边及 `currentColor`，默认显示 24 px，透明背景。SVG 含可访问名称，无脚本、字体、外部资源或嵌入位图。

来源：本次使用图像生成工具制作风格参考，再以简单矢量路径重新构造；不是复制外部图标库，也不是将生成位图嵌入 SVG。参考图和浏览器预览仅保存在系统 Temp，不作为运行时依赖。

网页内联 SVG 可继承文本颜色；独立解码时需明确指定 `currentColor` 的颜色。未来 egui 接入应缓存按主题／缩放生成的显示资源，不每帧解码。浏览器预览通过不等同于 egui 加载路径已验证。
