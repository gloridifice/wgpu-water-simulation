## Files and modifications in this project

| File | Source and processing |
| --- | --- |
| `challaborough_pillbox.glb` | Original downloaded model, unchanged in this project; original author metadata and embedded textures retained |
| `challaborough_pillbox.sweh` | Derivative single-layer heightfield generated by this project from the GLB, with valid-coverage flags; this project licenses the derivative under CC BY 4.0 and retains attribution to the original work |

Derivative processing applies glTF node transforms, excludes triangles entirely on the model bounding box bottom and four vertical clipping planes, and samples the highest surface from above. The default clipping tolerance is 0.002 model units, removing 4,264 triangles; the heightfield is 984×890. The original GLB is unchanged. Runtime display can apply the same clipping-plane cleanup and adjust model scale, placement, and water level. These operations were performed by this project and are not a hydrodynamic model provided or endorsed by the original author.
