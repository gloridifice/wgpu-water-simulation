`challaborough_pillbox.glb` is the original scan, unchanged. It contains 1,077,042 triangles, one double-sided unlit material, and a 4096×4096 JPEG. Photographic lighting in the texture is retained; sand directional lighting is not applied on top. Model scale has not been calibrated against measurements; scale, water level, and placement in the current scene are adjustable preview parameters.

## Obtaining assets (Git LFS)

The repository uses root `.gitattributes` to manage `*.glb` and `*.sweh` through Git LFS. Git commits store pointers, while binary model and heightfield contents are stored as LFS objects; other committed assets and history are not migrated.

After installing [Git LFS](https://git-lfs.com/), run from the cloned repository root:

```powershell
git lfs install --local
git lfs pull
git lfs ls-files
```

Do not use LFS pointer text as a model file. If LFS objects are missing, run `git lfs pull`; there is no need to rebake the supplied heightfield. Distributions must still include the actual binary assets and this directory's copyright notice.

During a normal `git push`, the Git LFS pre-push hook uploads the corresponding objects first; creating a local commit alone does not upload the model. Whether archive downloads include actual LFS objects depends on the hosting platform; cloning with Git and pulling LFS assets is recommended.

## Derived heightfield

`challaborough_pillbox.sweh` is a single-layer heightfield generated by this project from the model, using the same source and license. Default bake command:

```powershell
cargo run --release --bin terrain-bake
```

The default source is this directory's GLB, and the destination is this directory's `.sweh`. Cells are no larger than 0.05 model units, producing a 984×890 grid; model units are not assumed to equal meters accurately. The tool applies glTF node transforms, removes triangles entirely on the bounding box bottom or four vertical clipping planes (tolerance 0.002 model units), and rasterizes the remaining triangles from above, taking the highest intersection at each cell center. This default processing removes 4,264 clipping-plane triangles; runtime display uses the same cleanup rules. The upper clipping plane is not removed automatically.

This is an explicit scan-processing rule, not general semantic segmentation: natural planes in other models may require different parameters. `--cap-epsilon 0` disables cleanup. Cells with no hit retain an invalid marker; the tool does not guess the shape of caves, areas under overhangs, or missing scan regions.

```powershell
cargo run --release --bin terrain-bake -- --input assets/models/challaborough_pillbox.glb --output target/coast-preview.sweh --cell-size 0.1 --cap-epsilon 0.002
```

The tool creates only nonexistent outputs and does not overwrite existing files. Move the old file away before rebaking the official asset. If the model changes, a source SHA-256 mismatch prevents loading and requires rebaking. Baking does not read or write personal settings and does not require a GPU.

### File format v1

- 8-byte magic: `SWEHMAP1`.
- 4-byte little-endian JSON metadata length.
- UTF-8 JSON: version, source GLB SHA-256, source bounding box after node transforms, 2D resolution, clipping-plane tolerance.
- Cell-center array, X fastest, then Z. Each cell contains two little-endian `f32` values: height and coverage flag (0 or 1).

Heights use model scene coordinates, excluding user runtime translation, scaling, Y-axis rotation, or sea-level offset. Loading checks version, dimensions, data length, finite values, coverage flags, and source identity. This is not a PNG grayscale heightmap; no sRGB or gamma conversion is applied.

Both `.sweh` and GLB are runtime assets. Distribute `assets/models/` and both files alongside the executable; during development they can also be read from the repository root, with a fallback to the compile-time repository location. They do not depend on the original asset download directory.
