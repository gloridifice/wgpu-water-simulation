# 工作区与参数面板目标规范

## Scope and current contracts

本文是本变更的目标，不是已实现功能。当前界面只有一套 Dock 布局，参数保存不含 Dock。沿用 [当前架构](../../../../../architecture.md) 的 FFT／SWE 分工和 [浪花合约](../../../../../specs/gpu-spray.md) 的独立状态与错误语义；只改变 UI 组织及独立的布局保存。

## Requirements

### R1 固定导航与工作区

导航只有“场景、浅水、远海、着色、配置”五项，顺序固定，以 38×38 pt 正方形按钮仅显示居中的 24 pt SVG icon，hover 显示名称；未选中背景透明、无边框，选中态保持主题高亮；保留可访问名称、键盘焦点和互斥选中态。按钮间隔、侧栏四周留白均为 8 pt，圆角 8 pt；配置分隔线上下留白一致。导航不参与停靠，始终可达。右侧是当前分类的 Dock 区域，默认参数靠左、Viewport 占右侧主要空间。场景／浅水／远海／着色的参数侧分上下区：上区分别为场景与地形、SWE 与输入、波谱与波形、水体与天空；下区容纳各分类其他页签。配置保持单区。更新默认排列不覆盖已保存布局，仅新布局或显式重置应用。

每套工作区可以独立调整分隔、页签顺序、激活项、关闭／添加参数面板。添加菜单可选择其他工作区的可用面板；性能为通用面板。每套保留一个不可关闭、不可重复添加的 Viewport，不增加系统浮动窗口。

### R2 状态与保存

五套工作区共享模拟、草稿、相机和配置库；切换、停靠、关闭或恢复面板只修改 UI 状态。波谱和模型草稿继续显式应用。

分别保存五套布局和当前分类，普通重启恢复。“重置当前布局”只修改当前分类，保持其他布局、共享参数和命名配置不变。布局文件和模拟参数独立；旧配置缺少布局数据仍正常加载。`--no-settings`、只读 `--config`、快照和验证不隐式读写布局。损坏布局回退只影响 UI，错误可见，不覆盖原损坏文件直至用户明确重置／确认修复。

### R3 参数归属

| 工作区 | 面板／逻辑组 |
| --- | --- |
| 场景 | 场景与启用入口；沙坡／平底；模型变换与水位；模型计算域及边界；碰撞体 |
| 浅水 | 求解与采样；FFT 输入与混合；近岸前沿／背景源；泡沫输送与拖曳；单／双浓度寿命；沙地干燥历史；浪花发射与运动 |
| 远海 | Phillips 波谱；FFT 范围与采样；波高与挤浪；远海泡沫源与衰减 |
| 着色 | 水体光学；天空照明与散射；反射；共用泡沫显示与颜色；近岸材质／高度；小波法线；沙地材质；浪花尺寸／随机尺寸／软交界 |
| 配置 | 现有命名配置和保存错误 |

FFT 输入增益、过滤开关、截止与过渡波长、FFT 混合水深必须同归浅水。远海与近岸泡沫模拟状态仍独立；沙地干燥不归泡沫寿命。调试控件在所属功能组，播放和相机操作在常驻工具栏。

### R4 条件显示

以实际作用判定，不以“当前画面暂时看不出变化”判定。隐藏既不清空参数，也不触发额外重置。

| 条件 | 隐藏内容／必须保留的入口 |
| --- | --- |
| 没有有效海岸／模型场景或 SWE 关闭 | 隐藏纯 SWE 求解／输入／近岸泡沫／浪花子参数和纯依赖面板；保留场景、SWE 启用和必要错误入口 |
| 模型优先于沙坡 | 隐藏无效沙坡开关／坡度／岸线；保留模型关闭／应用入口及仍有效的补充海床 |
| 纯倾斜沙滩 | 隐藏无作用的平底深度；不隐藏沙地纹理参数 |
| 关闭水平挤浪 | 隐藏挤浪强度，保留挤浪开关 |
| 关闭短波过滤 | 隐藏截止波长和过渡宽度，保留过滤开关与可重新启用的预设操作 |
| 双浓度模式 | 隐藏旧惯性输送、拖曳、单浓度衰减及被覆盖的旧材质选择；显示新鲜／残余半衰期、转化比例；保留共用坐标周期与密度响应 |
| 单浓度模式 | 隐藏双浓度寿命参数；一阶 SWE 下隐藏不能选择的二阶泡沫输送控件 |
| 关闭水流拖曳 | 隐藏跟随倍率与响应时间；新生速度参数在单浓度路径下仍有效 |
| 关闭新生泡沫发射 | 隐藏源项调节，保留发射开关；已有泡沫的输送、衰减和显示仍可操作 |
| 压缩脊线模式 | 隐藏旧前沿采样距离和所有背景生成参数，显示窄带宽度和峰值显著度 |
| 非脊线模式 | 隐藏脊线专属宽度和显著度；前沿及背景分别成组 |
| 原型孔洞或双浓度覆盖 NSH | 隐藏无效的 NSH 纹理来源／尺寸／微法线／粗糙度；密度响应等共用参数按实际用途保留 |
| 原灰度材质 | 隐藏专属 NSH／原型／双浓度不透明度与材质调试控制；保留有效的共用颜色、坐标周期等 |
| 泡沫高度为零 | 隐藏高度阈值与过渡范围；保留最大高度控件以便恢复 |
| 关闭泡沫显示 | 隐藏纯泡沫外观依赖项，保留显示入口；泡沫生成／输送／衰减与可用的密度诊断不受影响 |
| 关闭浪花 | 隐藏其模拟与着色参数，保留启用入口和失败提示；不改水体或泡沫 |
| 关闭天空散射 | 隐藏反照率、积分步数及散射专属图表；保留天空颜色、强度、反射与其他仍有效光学参数 |
| 非光程调试 | 隐藏光程白色参考值；保留调试视图选择 |
| 沙地材质替代棋盘 | 隐藏不生效的棋盘／RGB 色带；不得仅因色带关闭而隐藏仍生效的普通棋盘尺寸 |

返回正常视图的选择器、启用入口、资源失败／配置保存错误不可被自身门控隐藏。碰撞体超出计算域时保留位置／尺寸编辑以便修复，不把整个碰撞体消失当成简化。

暂时隐藏的面板记住位置；条件恢复且用户没有主动关闭时复位。若隐藏期间原位置被用户改变，按现有锚点恢复，不撤销其他布局编辑。可用面板内容全部为空时不显示空标题或空 Dock 页签。

### R5 控件与图标

同一逻辑组共享两列表格，名称／控件宽度为 42%／58%，标题是普通字号加粗 Label；解释只在 hover，不增加常驻说明小字。保留必要状态、按钮和错误。

两到三项固定单选使用水平互斥按钮，选中状态与值一致。四项及以上或动态选项默认下拉／列表；普通开关保持复选框。精简可见标签而不丢算法名称和单位，控件不越界。无操作可做的“应用”“保存”等按钮可保留置灰和原因，不等同于不可用参数组。

五个图标采用同一 24×24 SVG 网格、单色圆端描边、主题着色，不使用 emoji、外部字体、远程资源、脚本或嵌入位图。浅水使用水面与坡底，远海使用卷浪，二者不得只有文字不同。

### R6 工具栏性能摘要

Dock 上方常驻工具栏横跨整个窗口宽度，左侧导航从其下方开始；操作控件左对齐，FPS、CPU 帧处理毫秒、GPU 主帧毫秒在最右侧右对齐；窄窗口放不下时性能摘要另起一行右对齐，不裁切。实际 SWE 开启时再显示 SWE GPU 毫秒。FPS／CPU 与性能页签使用同一 1 秒采样窗口；GPU 使用真实时间戳异步采样。GPU 主帧覆盖本帧主命令缓冲的模拟、场景及 GUI，不含 CPU 编码／提交等待、交换链呈现等待和额外回调缓冲；hover 明确口径。SWE 是主帧中的子区间，不与总 GPU 值相加。设备不支持、读取失败、等待采样和暂停空闲都有可辨识状态，不用零或 CPU 值伪装 GPU 结果。不每帧阻塞等 GPU。

## Boundaries, errors and compatibility

- 不修改参数默认值、范围、序列化兼容、CLI 优先级、物理／渲染算法或现有配置操作语义。
- 布局读取失败、未知工作区或面板、无效分割比例不会导致 GUI panic；只修复／回退受影响布局并报告问题。
- UI 隐藏保留值，用户显式功能切换引起的原有模拟重置照常发生；二者不能混淆。
- 配置只读、设备不支持 GPU timestamp、没有待应用修改均仍可显示必要信息。
- 当前项目默认显示范围之外的 CPU／独立实验工具不受此次导航重构影响。

## Acceptance scenarios

- **A1 五分类**：正常启动，五个纯 icon 正方形入口固定在 Dock 外，hover 显示名称；依次点击，右侧面板按 R3 切换，FFT → SWE 只在浅水默认布局中出现。
- **A2 独立布局**：浅水拖动面板并调宽，远海调另一布局；切回分别恢复。只重置浅水不影响远海；重新启动恢复当前分类和两套调整。
- **A3 共享状态**：暂停后编辑未应用波谱和模型草稿，切五个工作区；参数、草稿、时间和相机不变。跨工作区添加同一面板，显示同一值；不重复添加 Viewport。
- **A4 隐藏与恢复**：依次验证 R4 的门控，隐藏值不变，启用／恢复／纠错入口仍可达。将近岸面板移到自定义位置后关闭 SWE，再开启；恢复该面板位置。隐藏期间删除原锚点后恢复，也不得回滚其他布局。
- **A5 控件与尺寸**：在正常及窄参数栏、常用系统缩放下，按钮保持水平互斥、名称可换行，两列对齐；图标的浅水／远海含义可区分，深浅背景及焦点／选中态可辨认。
- **A6 保存隔离**：旧模拟配置无布局文件仍加载；载入／覆盖命名配置不改布局；专用测试路径下持久化成功。损坏布局只回退 UI，原参数和文件保留；只读与 `--no-settings` 前后文件不变。
- **A7 回归**：场景／波谱／模型应用和原有重置语义不变；相机输入仅由 Viewport 获取；CPU feature 构建不被 UI 资源依赖破坏。
- **A8 图标预览**：五个独立 SVG 可解析且无外链／位图，Temp HTML 展示实际尺寸、放大形状、选中／未选中、侧栏组合；明确这是浏览器预览，不声称已经实现 Dock。

- **A9 性能摘要**：实际窗口工具栏显示 FPS、CPU、GPU；开启 SWE 后出现 SWE 时间，关闭后隐藏。与性能面板口径一致，暂停时 SWE 空闲而 GPU 主帧继续更新；无时间戳支持时显示不支持，异步采样不阻塞。
