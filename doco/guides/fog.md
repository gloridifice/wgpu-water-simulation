# SWE 贴地雾实验场

## 启动

在仓库根目录运行，默认 `cargo run` 仍启动 Ocean：

```powershell
cargo run --release -p swe-fog
cargo run --release -p swe-fog -- --help
```

`swe-fog` 是独立的库与二进制，使用 Rust / wgpu / WGSL，复用 `crates/common/` 的窗口循环、设备、计时、egui/视口、Dock、相机数学及配置保存。不依赖根包的 FFT、Shore 或 Ocean Renderer，也不需要安装 Godot。

- 单击渲染视图：捕获鼠标；Esc：释放鼠标调参；捕获后 Q：退出。
- WASD：相机相对移动，斜向不加速；空格：落地后才可再次触发的跳跃，长按不连跳。
- 鼠标：第三人称环绕。玩家使用正常 9.81 m/s² 重力，雾的约化重力不影响玩家。
- 暂停只停止雾；玩家和相机仍能移动。暂停、重置或关闭玩家交互会清除待发动作，不在恢复时补放。
- 顶部“操作”菜单列出操作方法。程序初始不强制捕获鼠标。

地面为 64×64 米黄绿色网格，细线间隔 1 米、主线 5 米；胶囊高 1.8 米、半径 0.35 米。人物与相机均由 Rust 实现，不携带 Phantom Camera 或 Godot 运行时。

## 参数与显示

左侧竖向图标分段选择器切换“模拟、外观、配置”，悬停显示分类名称，当前分类保持高亮。三类各有独立 Dock 布局；切换、拖动和重排布局不重置模拟。每套布局都有不可关闭的渲染视图，参数面板可关闭或从“面板”菜单恢复。

所有数字沿用统一交互：左键横拖、Shift 精调、双击输入。**除渲染平滑强度和积分精度外，数字变化立即重置雾场，拖动中持续生效，不等松手**；同一帧多个变化合并为一次 GPU 重置。平滑强度和积分精度仅刷新渲染结果，不重置。暂停、玩家位置和相机保持不变。开关不触发重置；“水平雾顶初态”只在下一次重置时使用。

“模拟 → 初始化 → 网格分辨率”可选择地形原始网格或 64×64、128×128、256×256、512×512。默认原始网格已从 128×128 加密到 256×256；64×64 米场地保持原大小，格距从 0.5 米降至 0.25 米，单元数变为四倍。切换分辨率会重建地形、模拟和渲染绑定并重置雾，保留玩家、相机和暂停状态；顶部“诊断”可查看实际分辨率。更高分辨率增加计算量，选择随会话手动保存。

默认初始化为有符号 fBm：

```text
h = max(0, 0.25 m + 0.25 m × noise + (-0.2 m))
```

默认频率 0.32/m、3 层、种子 7。0.25 米是基础高度参数，不代表处处有 0.25 米厚的雾；默认分布包含无雾空隙。噪波仅用于初态，不是额外的渲染动画。细层频率过高时显示采样警告，参数仍允许编辑。

- 层厚 h 与面雾量 m 独立；体浓度为 m/max(h,ε)，垂直曲线使用归一化的 6s(1−s)。消散只减少 m，不直接缩减 h。
- 约化重力默认 0.02 m/s²；关闭时压力、地形源项与 CFL 波速同时使用零重力。关闭不清除已有惯性，重力也不会持续制造波浪。
- 默认微风 (0.05,0) m/s，以 20 秒响应时间趋近目标速度；消散半衰期 300 模拟秒。
- 消光强度默认 4、白雾亮度 0.8，仅用于外观。当前为线性颜色合成至 SDR/sRGB 目标，不是 Ocean 的 HDR/Bloom 管线；高亮度可能饱和。
- “外观 → 白雾外观 → 重建方式”使用 yummy_egui 分段选择器，在“双线性、SmoothStep、预平滑、B 样条”之间切换，默认与旧配置均为双线性。“预平滑”只在雾场更新或平滑强度变化后，用受障碍物与有效格约束的 3×3 小核生成渲染厚度和雾量，再沿用便宜的双线性积分；底高与模拟数据不改变。暂停且数据不变时复用缓存。其“平滑强度”范围 0–1、默认 0.6，零值旁路到原始双线性，修改立即生效、不重置，随会话手动保存。
- “SmoothStep”对 X/Z 的格间小数坐标分别应用 `t²(3−2t)`，再以此权重混合同样的 2×2 原始邻格，重建厚度、雾量和底高；保留格点值，不生成预平滑纹理。完整无阻挡邻域内过渡为 C1 连续，格点处斜率为零，视觉上可能更平坦；仍需结合积分精度观察边缘，不能保证消除所有网格伪影。
- “B 样条”用 4×4 邻格的非负三次核平滑厚度、雾量和底高，每个积分点还检查连通路径，渲染成本较高。所有模式切换立即生效，不重置雾、相机或玩家，不改网格分辨率；手动保存记录选择。
- “外观 → 白雾外观 → 积分精度”控制每个穿过的 XZ 网格内的**基础积分段数**，范围 2–32 段/格，默认及旧配置为 2。每段先检查射线是否可能穿过地面与雾顶之间的区域；候选段最多再二分 3 层，XZ 投影均不超过各自格距 1/64 时停止，叶段继续使用 Segment Coverage 积分。判断用重建邻域的高度上下界，而非仅看端点／中点是否在雾内；均匀层和竖直视线不额外细分。所有重建模式都适用，调整实时生效、暂停时可调、不重置，随会话手动保存。建议固定相机从 2 开始，再对比 8、16、32；无需先统一拉满精度，但候选区间细分仍增加 GPU 耗时，B 样条开销尤其明显。
- 视觉对照建议先暂停雾，固定相机切换重建；正常画面及“体积不透明度”诊断体现差异，层厚／面雾量／速度／雾顶诊断仍显示原始格点。平滑会柔化小尺度细节和空洞，不能替代提高沿视线的积分精度；不保证所有距离、角度和边界都无网格伪影。
- 诊断视图包括层厚、面雾量、速度、雾顶，以及实际积分的体积不透明度。最后一项便于把地面网格混叠与雾自身采样分开观察。

顶部显示真实 GPU 模拟时间、有效重力、层厚范围与最大速度。GPU 时间分为“模拟”和“场景雾”两个真实 timestamp 区间；后者包含按需预平滑、静态场景、胶囊和雾合成，不含 egui 或呈现等待，不是单独雾着色的净成本。不支持、等待或失败会明确显示，不以 CPU 时间代替。

## 玩家交互

“模拟 → 玩家交互”的移动模式默认选择“拖带与回旋”，可切换“原有脉冲”进行对照；两种模式均保留起跳与落地冲击：

- “拖带与回旋”：身体周围以实际碰撞后速度的 0.6 倍带动雾，默认半径 1.5 米、响应时间 0.3 模拟秒。起步及每走过 1 米，在后方释放一对旋向相反的尾涡；默认半径 2.2 米、角速度 1.2 弧度/模拟秒、中心后移 1 米、左右中心间距 2.8 米、响应时间 0.3 模拟秒。低速时旋转按速度比例减弱。
- 尾涡来源固定在出生位置，默认在 0.8 个启用交互时的物理秒内逐渐减弱并到期；到期只撤掉外力，雾继续保留惯性。停步立即撤掉身体拖带，尾源可继续短暂施力。最多保留 15 对，超额替换最早的来源；这是有界、单向的效果驱动，不是动态角色绕流边界。
- 可调拖带半径、速度比例、响应时间，以及尾涡半径、角速度、响应时间、后移、左右间距、发射间距和施力时间。响应时间越小，趋近目标速度越快；发射间距越小，尾迹越密；尾涡角速度零时不发射。数字变化仍立即重置雾；切换模式不重置，只清理旧交互来源。参数名称的悬停提示说明单位、范围和生效方式。
- “原有脉冲”：实际水平移动在起步时发出一次小冲量，之后默认每 0.12 物理秒发出一次；默认峰值速度 3 m/s、强度 0.1，完全重叠时单次峰值 Δu 约 0.3 m/s。冲量之间不施加移动拖曳，不叠加新拖带或尾涡。
- 起跳与落地各产生一次径向冲量。默认起跳强度 2.4、半径 0.9 米，形成小范围强冲击；默认落地强度 0.45、半径 1.8 米，局部冲击更弱、范围更宽。强度无量纲，完整竖直重叠时对应峰值速度增量约为 2.4／0.45 米/秒；落地继续按实际落地速度缩放（0.5–2 倍）。初次生成接地不算落地冲击。已保存的自定义数值不会被默认值覆盖；使用 `--no-settings` 可直接验收新默认值。
- 作用按气层和事件竖直范围的重叠比例加权；没有重叠则不受力。直接扰动只改水平动量，不改 h 或 m。
- 库调用方可继续使用原有纹理冲量／持续来源；新解析圆盘与涡旋复用原事件 ABI，不增加纹理层、GPU 缓冲或逐帧回读。旧配置缺少新字段时加载上述默认值，已有脉冲参数不会丢失。

视觉验收可用 `cargo run --release -p swe-fog -- --no-settings`，避免改动个人配置。单击视图后走直线、转弯、停步，观察尾迹是否留在路径上并继续回卷；Esc 释放鼠标后，在“玩家交互”调整尾涡角速度和响应时间，或切换移动模式做对照。默认格距 0.25 米，先使用约 2 米半径，再尝试小涡；“外观 → 诊断视图 → 速度”可辅助观察，最终外观仍需人工验收。

## 离线高度场

随 crate 提供 `assets/playground.scene.json` 的显式世界空间三角形和已经烘焙的 `assets/playground.fogterrain`。默认运行加载并校验原始资产；仅在面板、会话或 CLI 显式选择不同分辨率时，根据同一来源三角形重建内存地形及阻挡面，不修改烘焙文件，不用缩放旧网格代替地形查询。

```powershell
cargo run --release -p swe-fog -- --bake map.fogterrain
cargo run --release -p swe-fog -- --scene scene.json --bake map.fogterrain --domain -32,-32,64,64 --resolution 128x128
cargo run --release -p swe-fog -- --scene scene.json --terrain map.fogterrain --no-settings
# 窗口与导出也支持显式网格分辨率，覆盖本次载入会话的选择。
cargo run --release -p swe-fog -- --no-settings --resolution 512
```

输出路径必须不存在；已有资产不会被隐式覆盖。JSON 的 `floor` 和 `obstacle` 分别是世界坐标三角形数组，每个三角形由三个 `[x,y,z]` 顶点组成。它们对应原型的静态承载面与阻挡组，不是通用 glTF 场景导入器。

二进制格式记录版本、XZ 范围、矩形分辨率、来源 SHA256、高度、有效格和共享通行面。无命中保持无效，不能退回零高度；投影退化的薄竖墙仍阻挡通量。重叠表面只保留最高层，烘焙报告重叠计数，不支持桥上桥下两层雾。

默认资产编译期嵌入；重新烘焙默认场景后可用 `--terrain` 显式加载新资产，或替换 crate 资产后重新构建。Godot `.res` 不作为 Rust 的运行时格式。损坏或来源过期会报错并拒绝启动，不静默生成替代地形；这是 Rust CLI 的严格加载行为，与 Godot 原型“禁用雾但继续场景”的降级方式不同。

## 配置保存

- 默认使用已有 `configs/fog-settings.json`，否则使用用户目录的 `water-simulation/fog-settings.json`；与 Ocean 文件隔离。
- 顶部保存 / Ctrl+S 只显式写工作状态和配置库，不覆盖所选命名快照。配置面板可新建、重命名、删除及显式覆盖；默认快照只读。
- 相机、玩家位置、雾与交互参数保存于会话；不保存运行中的完整 GPU 场。载入配置会重新初始化场。
- 布局独立保存为同目录 `.workspaces.json` sidecar；只读配置和 `--no-settings` 不加载或保存个人布局。
- `--config PATH` 严格只读；损坏文件不会被自动改写或备份。离屏导出使用它选择参数，不使用 `--settings`。

## 检查与导出

```powershell
cargo test -p swe-fog
cargo run --release -p swe-fog -- --verify
cargo run --release -p swe-fog -- --no-settings --frames 600
cargo run --release -p swe-fog -- --snapshot fog.png --time 3
cargo run --release -p swe-fog -- --config parameters.json --dump state.json --time 1
```

PNG 和状态导出路径必须不存在。快照只包含场景、不包含 GUI，不能代替布局验收。`--time` 为离屏推进量，不使用墙钟；不因保存的暂停状态跳过暖机。导出不会读写隐式个人配置。JSON 状态包含实际 GPU 时间、故障与丢弃时间，以及 h/m/ux/uz 全场；全场同步回读仅用于显式导出与验证，不用于正常推进。

`--verify` 还用独立 f64 点密度积分核对自适应 Ray Marching：包含基础中点漏过的斜坡 1 cm 薄层和内部雾顶峰值、预平滑扩展到原始支持域之外的雾、反向／竖直视线及空区间。斜坡用例在未细分时得到零光学厚度，参考值为 0.8；三层细分后双线性结果约 0.768。所选正例误差在 5% 内，但这不是所有雾场的统一误差保证。

`--verify` 同时检查预平滑的解析脉冲响应、零／常数场、薄墙与无效格隔离、零强度旁路、暂停时强度缓存刷新，以及切换后完整模拟场不变。加速结构验证还包括长射线跨空块、反向／平行格面／角点／提前截断，以及 13×7 奇数矩形网格的末行末列、填充和所有 mip。

### 加速结构与分阶段计时

正常渲染使用两项优化：

1. **每格包络预计算**：在 GPU 上为所有格计算支持域的 h/m/b/雾顶上下界，供所有像素共享，不再沿每条射线重复读取 3×3／5×5 邻域。
2. **min/max 金字塔**：在包络上逐级归约，形成隐式四叉树；分层整数 DDA 可整块跳过不可能穿雾的区域。候选 4×4 区域内仍逐格积分，投影不足 8 格的短射线不查树，不以粗层积分代替叶段。

两张 RGBA32F 包络纹理在默认 256² 网格下连同全部 mip 约占 2.67 MiB。仅模拟发布、重建支持类型或相关预平滑强度变化时刷新；暂停、相机／窗口变化和积分精度调整复用缓存。所有构建在 GPU 完成，不回写模拟，不逐帧回读。

`--verify` 结束时在同一进程轮换三条编译期诊断路径，预热各 20 次、测量各 21 次，输出真实 GPU 时间的中位数。刷新帧重新发布相同的场并计入重建，缓存帧另列；预平滑、包络／金字塔构建、绘制和总耗时分开记录。各列为独立中位数，不要求分项之和严格等于总计。没有 timestamp 的设备明确跳过计时。诊断变体不新增 UI 或会话选项。

| 重建支持域 | 优化 1：每格包络 | 优化 1＋2：包络及全部 mip |
| --- | --- | --- |

缓存命中不编码这些 compute pass；计时器仍有约 0.002 ms 的边界开销，不应当作实际重建成本。

**本次收益主要来自优化 1；追加四叉树比仅预计算包络慢约 1.3%–8.3%，稀疏对照也没有额外提速。** 构建成本较小，遍历成本与有限的跳过收益仍需权衡，不能把整体相对基线的改善归功于四叉树。B 样条仍有大量叶段 4×4 重建，当前不承诺跨设备或其他雾场的速度优势。

基准外另以固定 320×200 不透明度图像对照：仅优化 1 的九组图像逐字节一致；完整层级中两组各有 1/64,000 像素相差 1/255，其余一致。层级跳跃会重新计算格面距离，相对逐格累加存在浮点差异；该结果不是任意视角的逐位相同保证。独立 f64 密度积分检查与原渲染／模拟验证均继续运行。

当前检查覆盖：地形/CLI/配置/玩家运动/交互节拍与尾源位置/寿命/数量上限契约；真实 egui 拖动中重置意图、Shift 精调和精确输入；实际 GPU 的 60 秒静水平衡和守恒、两种空间阶数的薄墙输送、风/消散解析解、冲量纹理/旋转/竖直重叠、持续源时间响应、解析拖带与零目标减速、双阶成对反向旋转/撤源惯性/雾量守恒/干格与竖直保护、1 cm 薄层积分、角色遮挡、雾内相机和暂停/环绕返回稳定性。

摩尔纹检查固定使用频率 1.05/m、2 层的非均匀初态，在掠地、正常及俯视三个角度，将实际体积不透明度与 3 倍分辨率平均参考比较。256×256 默认网格、双线性与每格 2 个基础段＋自适应细分，在 RTX 3070 / Vulkan 上实测 MAE 约 0.00143、0.00076、0.00055（0..1）。该对照刻意排除恒定屏幕线宽的地面网格颜色，不能把网格随分辨率改变的外观误算为雾混叠。

Windows 窗口已做有限帧运行和截图检查；系统焦点/输入权限阻止了自动桌面键鼠驱动，因此它不算通过。egui 输入测试不替代实际桌面 WASD、跳跃、捕获/释放及所有 Dock 手势的人工验收。

## 渲染与范围限制

当前渲染不是移植 Godot 的 froxel 系统：视线先求静态三角形与胶囊的最近交点，再在深度截断范围内按 XZ 格分段，以重建支持域的高度包络筛选候选区间，最多二分 3 层后对叶段的局部垂直密度解析积分；XZ 使用通行面约束的双线性、SmoothStep、预平滑或 B 样条重建，每格 2–32 个基础段可调，默认 2。细分最多产生每基础段 8 个叶段，使用固定容量栈；包络／金字塔是独立的 GPU 渲染派生纹理，不改变模拟状态或引入逐帧回读。四条固定子像素视线覆盖像素足迹，没有时间抖动、历史重投影或逐帧 GPU→CPU 回读。

垂直曲线在局部参数固定时解析准确；高度包络保护候选区间剔除，但叶段仍冻结局部层参数。有限层数不能保证任意窄结构无漏采，严格无漏检还需要更精确的几何求交；变化中的二维场与屏幕覆盖仍是有限采样近似，不承诺所有视角完全无混叠。原型的原生体积光照改为可调白色源项，不包含三维细节湍流、体积阴影或多层气体。静态场景求交目前直接遍历至多 4096 个三角形，角色使用高度场/通行面的运动约束，不是完整刚体物理引擎。相机的球形跟随臂对相同静态三角形裁切；玩家不受雾反作用。不承诺跨设备固定毫秒预算，尚未接入 Ocean 的同屏水雾合成。
