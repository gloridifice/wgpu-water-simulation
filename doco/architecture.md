# 当前架构

本文记录当前代码已实现的边界；未实现方案保存在变更目录，不视为当前功能。

## 程序入口

- Rust 2024 workspace，根包 `water-simulation` 默认启用 `ocean` feature；默认成员只有根包，`cargo run` 启动 GPU Ocean。
- `src/bin/ocean.rs` 提供 GPU 海洋入口、验证与预览参数。
- `src/bin/slider_lab.rs` 与 `src/ocean/labs/slider_lab/` 提供独立矩形滑块外观窗口，与正式面板共用 `yummy_egui::ParameterSlider`，复用库默认主题与参数网格；实验调节仅影响本窗口，不运行模拟、不读写配置。启动与交互见 [滑块外观实验](guides/slider-lab.md)。
- `src/bin/ocean_profile.rs` 提供只读配置的离屏生产路径剖析：固定 1/60 模拟秒推进，预热后分开记录 FFT、远海泡沫、完整 SWE（含浪花源与复制）、粒子和绘制的 GPU timestamp；末尾回读状态／图像作 A/B，不包含 UI 或呈现。支持 pass 内时间戳时通过 `render/timing.rs` 细分绘制阶段而不拆分 render pass，初始化帧与预热后的统计分开；query 按设备上限分批；`--optics-ab` 在同一模拟状态上轮换四种焦散／折射组合进行配对测量，不额外推进物理；`--optics-methods` 则对照全关、物理焦散搭配快速折射、物理焦散搭配物理折射和原配置。运行说明同见 [泡沫诊断与基准测试](guides/foam-lab.md#生产路径离屏剖析)。
- `src/bin/foam_lab.rs` 提供独立离线泡沫输送对照：默认诊断入口调用生产泡沫通量／源项／纹理运动，在固定解析水流下输出密度快照及误差；`foam_lab/benchmark.rs` 的 `--benchmark` 模式则调用生产 SWE 管线，在固定稀疏／密集／模型地形／障碍物及模型双浓度＋非零入射波输入下预热并重复计时、导出单步状态。两者均不读写个人配置，见 [泡沫诊断与基准测试](guides/foam-lab.md)。
- `crates/tui-2d-prototype/` 是独立 CPU 包：`src/main.rs` 统一选择二维 PIC／一维浅水及 TUI／批处理，`src/pic/`、`src/solver.rs` 提供不依赖终端的求解器，`src/tui/`、`src/shallow_tui/` 负责交互。测试与 `pic_probe` 示例归该包所有，Cargo 包名为 `tui-2d-prototype`，库名为 `tui_2d_prototype`，二进制仍名为 `water-simulation`；从根目录用 `cargo run -p tui-2d-prototype` 启动。
- 根包不依赖 CPU 包、Ratatui 或 Crossterm；根包与 CPU 包共用根 `Cargo.lock` 和构建目录，`cargo test --workspace` 覆盖这两个包；组件库 `yummy_egui` 从 crates.io 获取，不是 workspace 成员。`crates/tall-cell-fluid/` 保持独立 workspace，不纳入此工作区。

## GPU 海洋

`src/ocean/` 按职责分为 `app/`（窗口与快照）、`gpu/`（设备与计时）、`parameters/`（参数默认值与校验）、`simulation/`（远海、近岸、浪花）、`scene/`（模型、地形、碰撞体）、`render/`（场景绘制、光学、纹理）、`ui/`（面板和布局）、`settings/`（会话与命名库）、`labs/`（实验）。`camera.rs` 放共享相机和 CameraUniform；不依赖窗口。参数层不依赖应用、界面或 GPU 资源。`gpu/context.rs` 不引用模拟或渲染。

`ocean/mod.rs` 保留原 `shore`、`foam`、`spectrum`、`spray`、`model`、`terrain`、`collider`、`optics`、`skylight`、`viewer`、`foam_weight_lab` 公开路径；`gpu/mod.rs` 保留 Gpu、Ocean、Renderer、CameraUniform、Error 的重导出。兼容入口不持有第二套实现；内部使用实际职责路径。原天空深度图入口仍由兼容门面导出，图表实现归 `ui/panels/optics.rs`，天空计算不依赖 GUI。下文 Rust 简写路径相对于 `src/ocean/`。

- WGSL 文件归所属模块的 `shaders/` 子目录：FFT/远海泡沫在 `simulation/offshore/`，SWE 公共定义/计算/读取在 `simulation/nearshore/`，浪花在 `simulation/spray/`，绘制与光学在 `render/`，颜色 mip 在 `render/textures/`，泡沫权重实验在 `labs/foam_weight_lab/`。离线输送诊断保留 `src/bin/foam_lab/shaders/`；独立液体库分别使用 `src/gpu/shaders/` 和 `src/demo/shaders/`。Rust 相对源文件使用 `include_str!` / `include_bytes!` 编译期嵌入；跨模块引用唯一原件，保留字节内容和拼接顺序，不依赖运行目录或外部着色器文件。
- `simulation/offshore/spectrum.rs` 与 `fft.rs::Ocean`：波谱初始化、GPU 演化、逆 FFT，以及向近岸提供过滤后的波浪输入。
- `simulation/nearshore/mod.rs::Shore` 与所属 `shore*.wgsl`：局部二维 SWE、一阶/二阶求解、水面泡沫输送和沙滩湿润历史。耦合方向为 FFT → SWE；`uniform.rs` 保留原 CPU → WGSL 布局。二阶水体按轴复用五格邻域、三份重构及匹配床面源项，不增加 pass 或网格缓冲。模型单元中心床面直接索引上传网格，与碰撞体编辑共用同一查询；渲染任意世界坐标仍插值。正常推进只在 FFT 松弛带读取入射波，重置仍全域初始化；CFL 与 RK2 阶段不变。
- 默认单浓度模式的近岸泡沫量与动量共用守恒 Rusanov 通量；`foam_transport_order` 默认 1，在二阶 SWE 下可启用受限 MUSCL 空间重构。密度与动量共享正性／速度约束，干湿、障碍物和域边缘局部退回一阶；不改变源项、拖曳或材质。`foam-lab` 独立选择空间／时间阶数并用相同 CFL 对照，设备支持时记录 GPU timestamp。
- MUSCL 泡沫按轴复用五格邻域的水深、密度、动量和地形阻挡，中心斜率供两侧共用，不增加生产网格缓冲区或计算 pass。`Shore::solver_pipeline` 按水体／泡沫阶数惰性编译并缓存三个共享绑定布局的管线，用 WGSL override 去掉未启用的求解分支；首次使用可能有编译开销。诊断入口可保留 uniform 动态选择。
- 近岸源项保留旧前沿／背景路径；默认关闭的 `foam_ridge_enabled` 实验在同一 SWE 阶段沿局部流向读取五点速度，只向局部压缩峰窄带发射，并禁用背景源。它不是 FFT/J 调制，也不改动水动力、输送、拖曳、衰减或材质。`foam_emission_enabled` 停发但不清空历史；状态第三块的 x/y 在实验或诊断视图下存最近子步实际源率／权重，z/w 保持水面高程／速度含义。`simulation/nearshore/verification/foam_ridge.rs` 通过完整 GPU 求解调度验证窄带、切向连通、矩形网格／旋转、干湿保护、两阶注入和停发后的守恒输送。尚无自动波前追踪／滞回，不保证网状形态。
- `foam_dual_phase` 是默认关闭的双浓度实验，和默认惯性／守恒路径互斥。现有密度槽保存新鲜 N + 水面残余 R，第五块 w 保存 R，五块 storage 大小不变；R 不属于沙地。开启后两者共用 SWE 粗速度与半拉格朗日回溯，并同时应用面积压缩／膨胀响应，不再叠加旧通量、拖曳或单浓度衰减。密度输送与纹理运动复用同一回溯位置和实际输运速度，但浓度的障碍物通路检查、纹理的湿贡献者归一化仍独立。所有现有源只直接注入 N，每个完整子步联合解析积分生成、N→R 转化与独立衰减；默认半衰期 1.4／9 模拟秒，退出转化比例 0.65。切换模式重置 SWE 历史，寿命参数实时更新；暂停、干湿、重置和碰撞体编辑覆盖 R。`simulation/nearshore/verification/foam_dual.rs` 检查实际 GPU 解析解、两阶调度和输运／边界行为。此 SL 路径不承诺严格质量守恒或整体帧率无关。
- `Shore::encode` 按稳定步长拆分子步；二阶有预测与校正阶段。预测缓冲仍分配五块空间，但正常预测只写守恒量块及泡沫动量块（每格共 32 字节，动量块 zw 清零），校正所需显示／纹理／湿润历史从子步初始状态读取；完整结果仍写五块。完整子步在 field／previous 间交替输出，预测、校正及初始历史绑定随角色切换，帧末只复制一次，使两个完整场重新一致；渲染、暂停和碰撞体编辑仍消费固定的公共 field。`simulated_dt` 是本次实际推进量，长帧可能被限制，不能直接用墙钟时间替代。
- `simulation/offshore/foam.rs` 与所属 `foam.wgsl`：远海泡沫与当前位移雅可比，独立于近岸泡沫。
- `simulation/spray/mod.rs` 与所属 `spray*.wgsl`：近岸纹理浪花。Shore 持有 `SpraySource`，每完成 SWE 子步按当前／初始场角色选择绑定，向独立网格 storage buffer 累积发射信号；Renderer 持有 `SprayParticles`，消费信号，维护 GPU 余量、双粒子列表和间接绘制参数。粒子不反作用水体或泡沫，运行时不回读信号/粒子计数。配置放在 `OpticsConfig::spray`，默认关闭。
- `app/viewer.rs`：窗口、配置应用和帧调度；正常帧先计算 FFT、远海泡沫和 SWE，再编码粒子更新，最后调用场景、浪花和 GUI 绘制。`app/snapshot.rs` 保留离屏暖机与调度，同样推进粒子；两条路径没有合并或重排。
- `render/caustics/` 负责平底／沙坡及静态礁石高度场的可选太阳焦散：compute 读取共享 FFT／SWE 波面，平面解析求交，模型查询打包的 min/max 四叉层级（地形变化时重建，叶层保守覆盖双线性邻域，候选区间求最近根）；光束面积比向 512×512 `Rgba16Float` 世界空间贴图加法累积。`Renderer` 在水底预绘制前编码，SWE 重建时重绑。沙地替换直射光，扫描模型在水面合成中对匹配高度场的水下接收点叠加聚光增亮，保留 unlit 基色。`render/shaders/{scene_types,surface,water_light,caustic_sample}.wgsl` 共享类型、波面、接收几何与光照采样。观察视线折射独立开关：平底／沙坡解析交点并校验屏幕深度；模型由 `screen_depth.rs` 在不透明预绘制后逐帧构建 min/max 深度 mip，`screen_trace.wgsl` 分层查询，命中更新背景、光程和散射方向，失效回退直线。两项默认关闭且不回写模拟。焦散 Tab 提供关闭和物理，折射 Tab 提供关闭、快速和物理。旧配置继续使用原启用字段，折射方法缺省为物理。快速折射由 `fast_refraction.wgsl` 做一次局部平面估计、UV 限幅及深度遮罩采样，不构建分层深度。未选中的物理 pass 不编码。参数及单层高度场／屏幕空间边界见 [水底焦散与折射](guides/ocean.md#水底焦散与折射)；真实 GPU 检查归 `render/verification/optics.rs` 与 `render/caustics/verification.rs`，可用 `--verify-optics` 单独运行。
- `render/renderer.rs::Renderer` 持有 `Shore`，组织天空、海底、模型与水面绘制。远海和局部 SWE 水面都使用索引网格；`render/mesh.rs` 为远海生成 UV 顶点与索引，默认方格，也可选保持相近三角形数量的错行近正三角形网格。偶数行与共享周期边界保证 3×3 拼接；WGSL 从顶点 UV 读取原 FFT 场，位移与法线算法不变。只修改远海绘制拓扑／密度时，`app/viewer.rs` 仅重建绘制缓冲，保留 FFT、SWE、泡沫与浪花历史。局部索引仍是方格，随 SWE 分辨率重建，不受远海开关影响。CPU 测试检查数量预算、形状、绕序及周期边；`render/verification/mesh.rs` 经 `--verify-optics` 检查实际绘制覆盖与切换回退。水面写入 `Depth32Float` 深度；主深度具有 `RENDER_ATTACHMENT | TEXTURE_BINDING` 用途，场景 pass 保存深度，后续浪花 pass 只采样，不把该深度同时挂为可写附件。
- `render/post_process.rs` 与 `render/shaders/{post_process,agx}.wgsl` 负责显示路径的 HDR／Bloom。窗口、快照与离屏剖析使用 `Renderer::new_display`，将完整场景及浪花绘制到 `Rgba16Float` 后输出 SDR；`Renderer::new` 保留物理验证所用原始线性输出。`OpticsConfig::post_process` 默认关闭、兼容缺失字段，独立 uniform 不改变光学／SWE 布局。总开关启用后先曝光，可独立启停 Bloom 与 AgX。Bloom 按线性 RGB 峰值和软阈值提取高光，经最多六层独立降／上采样目标与归一化帐篷滤波合成；AgX 采用 Godot 4.6 的通用 Rec.709 矩阵＋allenwp 解析近似，固定中灰 0.18、对比度 1.25、白点 16.29，不按水体或材质调色。`agx.wgsl` 保留来源与 MIT 许可。独立开关缺省均为 true，仍受默认关闭的总开关约束；uniform 复用原 32 字节布局的空闲分量。输出为显示线性 RGB，最终 sRGB 目标只编码一次。关闭总开关或诊断视图仅输出原颜色；关闭 Bloom 或强度零跳过泛光金字塔；GUI 始终在后处理之后。resize 重建目标和绑定，不重置模拟；正常帧不回读。`render/timing.rs` 增加 `hdr_bloom_composite` GPU 区间；`render/verification/post_process.rs` 经 `--verify-optics`／完整验证检查参考颜色、灰阶单调性、中灰、RGB／CMY 极亮去饱和、-8／0／+8 档曝光、实际 sRGB 输出编码、独立开关、扩散、旁路和尺寸边界。参数入口与范围见 [HDR 与 Bloom 后处理](guides/ocean.md#hdr-与-bloom-后处理)。
- 水面 SSR 与模型物理折射共用不透明场景颜色、深度金字塔和分层遍历。同帧任一效果需要时构建一次金字塔。SSR 用同一波面法线计算反射方向，按命中点附近的波面高度筛除水下样本；屏幕边缘和距离上限渐隐到天空反射。SSR 默认关闭。
- `render/shaders/render.wgsl` 用介电 Cook–Torrance BRDF 计算水面的太阳直射高光，包含各向同性 GGX、带高度相关性的 Smith 遮蔽和按折射率计算的 Schlick 菲涅耳。天空与 SSR 仍按镜面方向采样，以视角菲涅耳权重与水体介质合成。天空背景绘制太阳盘，水面环境采样只保留天光与光晕，太阳盘的水面贡献由 BRDF 表达。共用折射率独立于观察折射模式生效。
- `render/shaders/surface.wgsl` 的近岸小波法线对 FFT 格点的 1 格／4 格中心差分坡度之差做周期 Catmull–Rom 双三次重建，消除双线性坡度的跨格导数突变；格点值、增益、干湿及足迹渐隐不变。水面与泡沫复用小波坡度、保留各自基础法线，焦散光线使用同一重建及自己的采样足迹。不新增场缓冲或 pass，不修改 FFT 主水面几何／顶点法线和 SWE 模拟；`render/verification/surface.rs` 经 `--verify-optics`／完整验证检查真实 GPU 法线。
- 近岸材质坐标跟随泡沫输运速度；默认开启的 `foam_texture_distortion` 仅控制渲染是否使用输运坐标，关闭时用固定世界坐标，不停止位移历史或浓度更新，通过 `foam_velocity.w` 传递关闭标记，不改变 uniform 布局。双相位重置周期由 `foam_texture_period` 控制（默认 2 模拟秒，0 为持续输运）；只重置不可见的坐标层，不修改密度／动量。`foam_prototype` 默认关闭，开启后在输运坐标上使用三尺度 value noise 和密度阈值显示孔洞，沿用现有光学、颜色和密度尺度参数；不使用 NSH 微法线。材质调试 5 显示输运坐标网格。此阶段没有新增细波传播、撞岩源或高分辨率泡沫场。
- 双浓度实验的 N 外观在 `ui/panels/foam_material.rs` 使用分段选择器切换常数／噪波／纹理，默认仍为噪波。常数阈值默认 0.5；噪波保留原两尺度三角格梯度噪声、细层旋转／偏移及每米 0.8／2.5 的频率、0.3 的细层占比，两模式保留原密度响应与柔和过渡。纹理模式只将 N 浓度送入共享 `nsh_material_phase`，复用已绑定的三层 NSH、粗细采样、输运坐标雅可比变换后的微法线和粗糙度光照；N 的纹理来源、尺寸、微法线、粗糙度与孔隙覆盖参考值独立保存，不覆盖单浓度材质或调试色标。R 始终保留多尺度窄带噪声和原宏观法线光照；两者分别计算预乘色，再按 N 覆盖 R 合成，每个坐标相位先着色再混合。共用不透明度密度尺度仍用于两者的指数响应；纹理模式只改变 N 的浓度到可见覆盖／光照映射，不改变浓度输送、生成、转化、衰减或几何。N 外观和 N/R 透明度的六个对齐 vec4 uniform 与共享 WGSL 定义一致，仅供材质使用，子步上传／复制大小仍由 Rust 结构大小计算；切换或编辑不重置历史。各模式保留零浓度／薄水保护，使用同一水面几何，没有细尺度湍流或单气泡。渲染成分选项可显示全部、仅 N 或仅 R，同步筛选外观高度，单独查看时隐藏远海泡沫；通过 ShoreUniform.density.w 传递，关闭双浓度时不生效。密度调试 6／9／10 分别读取 N+R／N／R，不经过材质阈值；双坐标重置周期继续有效。真实 GPU 验证检查三套 N 纹理与原 NSH 的纯 N 渲染一致、独立参数生效、R 光照／法线／不透明度及密度视图隔离，以及两阶 SWE 的完整状态不受 N 外观影响。参数见 [Ocean 使用说明](guides/ocean.md)。
- 双浓度 N／R 的 `foam_*_density_opacity` 开关默认关闭；开启后在各自材质覆盖之后叠乘 `pow(clamp(自身浓度／独立范围,0,1),p)`，范围为 0～10、幂值为 0.1～5，均默认 1。范围零以正浓度 1／零浓度 0 的极限阶跃处理，不执行除零。生产 `concentration_opacity` 只返回附加光学因子，同时缩放本类预乘色与不透明度后再按 N over R 合成；N 三种材质均可用，R 参数不影响 N。UI 在各自外观组内按开关条件显示参数，保留关闭时的设置，实时生效、不重置、不改变求解器或密度调试。GPU 数值检查以独立 f64 幂函数核对边界，生产光栅检查验证两类的独立因子及正确的颜色／alpha 混合。
- `render.wgsl` 的近岸 NSH 泡沫保留双相位孔隙覆盖，使用原始面密度的指数响应控制连续不透明度；`ShoreConfig::foam_opacity_scale` 仅控制外观，不修改密度／动量或重置历史。原灰度和远海泡沫路径独立。
- `parameters/` 保留原参数类型名称、字段、默认值及校验。`OpticsConfig` 仍是既有场景参数聚合，不改变序列化结构。`render/{optics,skylight,seabed,model}.rs` 与所属着色器负责光学、水底、天空与模型绘制；`scene/{terrain,collider,model}.rs` 提供地形、碰撞几何与导入模型数据。
- `render/textures/sand.rs` 与所属 `color_mips.wgsl`：沙地和导入模型颜色贴图在 CPU 解码 JPEG、上传原始层后，通过 GPU render pass 在线性空间生成完整 sRGB mip 链，不同步等待 GPU；每级写回 8 位 sRGB。沙地法线／标量贴图保留 CPU 过滤。`sand::verify` 回读实际 GPU mip，检查线性光平均及矩形纹理边界。

## 界面、配置与验证

- 通用控件由 crates.io 的 `yummy_egui` 0.1 系列提供（最低 0.1.2），搭配 egui 0.34.3、egui_dock 0.19.1 与 wgpu 29；库源码及主题配置不存储在本仓库。Ocean、两个界面实验和独立 `tall-cell-fluid` demo 使用 `Theme::default()`，Dock 使用其 `dock_style()`，不读取或保存外部主题。标题统一使用 h3；字体仍由各宿主安装，Ocean 使用 `ui/fonts.rs` 安装 MiSans。`tall-cell-fluid` 的 UI 依赖仍仅在 `demo` feature 下启用，不改变其独立 workspace 和求解器边界。接入约定见 [yummy_egui](guides/yummy-egui.md)。

- `ui/gui.rs` 使用 egui_dock，顶部常驻工具栏及性能摘要，左侧固定“场景、浅水、远海、着色、配置”导航，使用 `yummy_egui::IconSegmentedControl::vertical()` 连续竖向分段选择器，保留 SVG 图标和中文提示；五套独立布局默认参数靠左、渲染视图靠右，共享模拟、草稿与相机。`ui/workspace/` 维护包含临时隐藏面板的规范布局；各布局及当前分类独立保存到可写会话旁的 `.workspaces.json` sidecar，只读／无保存模式不隐式读写。界面合约见 [工作区界面规范](specs/workspace-ui.md)。`ui/panels/` 按职责拆分面板，共用 `yummy_egui` 的参数列表和控件；操作按钮显式使用 `PanelButton` 填满所属单元格：保留原生 egui 按钮的边框与交互，文字在沿用主题 padding 的内容区居中；margin 在内嵌组件主题中默认为上下各 4 pt、左右 0，不参与点击，不写入参数或布局文件。`action_row` 等宽排列并在每按钮扣除 margin 后不足 96 pt 时整组纵向排列，不改变全局按钮样式；`ui/workspace/{mod,store}.rs` 管理工作区与独立布局 sidecar。`settings/{session,library,store}.rs` 分别管理当前参数快照、命名库与加载/原子手动保存。仅顶部“保存”／Ctrl+S 或配置面板“保存配置”触发写盘；编辑、配置载入、失焦与退出不写会话，失败需手动重试。顶部显示未保存状态及保存结果；顶部保存不覆盖命名快照，Dock 布局仍独立自动保存。`SavedSettings` 使用默认值兼容缺失字段，读取路径由 `default_path()` 决定：当前工作目录已有 `configs/ocean-settings.json` 时使用该 Git 跟踪会话，否则回退原用户目录；显式 `--settings` 优先。`--config` 严格只读加载顶层会话，用于窗口和快照，不自动保存或替换坏文件。快照保留指定相机／远海泡沫参数，支持模拟时间发射窗口；均不改写配置。原会话、命名库及派生礁石实验配置见 [../configs/README.md](../configs/README.md)。
- `yummy_egui::ParameterSlider` 给面板原生 egui Slider 增加等高圆角背景与窄竖条皮肤，悬浮／拖动改变竖条宽高和亮度，不绘制描边。输入、数值编辑、整数／步长、对数及 clamping 继续由 egui 处理；独立显示映射仅支持当前面板的有限线性范围和非负对数范围，不改参数默认值或配置格式。
- 配置面板使用 `yummy_egui::SelectionList`，容器只负责滚动、全宽条目和原生响应；配置加载、选中状态、失败回滚及增删改仍归 `ui/panels/configuration.rs` 和 `settings/`。点击已选项仍可重新载入，无保存模式仍允许选择。参数列表的布局与滑块交互测试归组件库，配置业务和 Dock／相机测试保留在根包。
- `verify.rs` 只组织完整 GPU 行为检查；DFT/耦合、近岸、浪花及渲染验证归各自 `verification.rs` 或 `verification/`，仍编译到非测试程序供 CLI 调用，不通过暴露私有字段来迁移。`gpu/timer.rs` 使用设备支持的 GPU timestamp；功能运行不能依赖同步回读。
- 配置、特性边界、参数面板和资源许可约束见根目录 `AGENTS.md`；使用与算法指南集中在 `doco/guides/`，包括 [Ocean](guides/ocean.md)、[CPU PIC](guides/pic.md)、[一维浅水](guides/shallow.md) 和 [泡沫诊断](guides/foam-lab.md)。根目录 `README.md` 提供项目入口，`doco/specs/` 保留精确行为合约。
