# 程序化湖泊动画

## 范围

`OpticsConfig::lake.enabled` 选择非物理的湖泊动画水面。场景面板与 `--lake` 提供完整湖泊预设；原沙滩／岩岸预设关闭湖泊。湖泊可叠加与海洋共用的 FFT 波浪，不推进 SWE、两类泡沫或浪花，保留其配置值。独立 CPU 包和 common 框架不依赖此业务。

## 场景与传播场

- 海平面为世界 Y=0，湖心为 XZ 原点。外岸线由正的周期径向噪波半径定义，每条湖心射线仅有一个外岸交点；基础半径 8～100 米，不规则度 0～0.35。场景范围为基础半径的三倍边长。
- 湖底为带低幅噪波的碗状单层高度场；岩石为粗糙椭圆丘形高度几何，不含悬挑。岩石与床面取最大高度，渲染、干湿与深度共用这份数据，不另外使用不相关碰撞代理。
- 分辨率 128²／256²／512²，默认 256²；最大水深参数 0.5～12 米，岩石最多 32 个、基础水平尺寸 0.5～8 米。固定场景种子生成相同网格；候选重叠则跳过，显示实际生成数，每第三个候选尝试水下岩石。
- 深度模式坐标为 `max(-床高,0) / 场内最大静水深度`。完全水下岩石可改变该坐标，不改变水域掩码。
- SDF 是统一网格上到干湿边界的二维欧氏有符号距离，水内正、干域负，边界误差为网格尺度；包含外岸和露水岩石孔洞。传播坐标为正 SDF 除以场内最大正 SDF。它不是曼哈顿距离、湖心径向距离或绕障碍传播时间。
- 两模式传播坐标无量纲，入射由近岸向湖内增大、反射减小；速度单位为坐标／模拟秒，宽度单位为坐标。模式独立保存内侧折返坐标（兼容字段 `start`）、速度、宽度和近岸发射坐标（兼容字段 `reflection`）。要求 `0 < 近岸发射坐标 < 内侧折返坐标 < 1`，所有参数有限。
- 平台／中轴低梯度区域可减弱显示，等值线可分裂、合并或围绕岩石出现多段，不承诺单一连通波前、真实绕射、遮挡后的能量输运或世界恒速。

## 共享 FFT 与水体材质

- 海洋和程序水共用 `simulation/spectral::FftWaves`、波谱生成及周期采样实现；同一应用内使用相同 `ocean` 参数与 GPU 输出，不维护第二套湖泊波谱。共享模块不依赖 SWE、湖泊或桌面框架；近岸输入过滤仍同时作用于水位和匹配动量，不改变显示通道。
- `lake.fft_strength` 是 FFT 垂直波高的无量纲倍率，有限值 0～1，实时生效、不清空沿岸波。缺字段默认 0，保持旧湖泊配置的纯程序波行为；新“湖泊场景”预设为 0.2。强度为 0 时不编码湖泊 FFT。
- 叠加按世界坐标米制映射到共享周期场。`lake.fft_shore_fade` 缺字段默认 true，启用时在静水深度 0～0.5 米和正岸距 0～1 米内 SmoothStep 渐隐；关闭时不应用这两项衰减，仍保留干地屏蔽和最终波谷限制。开关实时生效、不重置波。该遮罩独立于深度／SDF 传播模式；不采用 FFT 水平挤浪，不搬动岸线／岩石占地。先叠加 FFT 与沿岸波，再约束最终波谷并生成高度一致的坡度。
- FFT 与沿岸波使用同一湖泊模拟时钟；暂停冻结相位，清空仅移除沿岸波及反射预约，不清空 FFT；地形／模式／重置操作重新计时。波谱、尺寸、种子或 FFT 分辨率应用会重建资源、重置湖泊历史，保留暂停与相机；仅修改远海绘制拓扑／密度不重置湖泊。
- 海洋和程序水共用 `render/water/` 的光路、介质、反射／菲涅耳、高光及光学诊断着色；不复制另一套湖泊材质。水域掩码、几何、泡沫与支持能力仍由场景适配；共用着色不代表湖泊已支持物理焦散／物理折射。

## 卡通岸边泡沫

湖泊独立的渲染泡沫使用米制 SDF，在外岸与露水岩石附近叠加不规则接触白边及渐隐胞状网纹，不修改水体基础颜色或共用光学参数。胞状边界使用整数哈希固定站点、到垂直平分线的距离及平滑交汇生成圆角孔洞；多尺度坐标扰动、轻度方向拉伸、线宽变化和断裂遮罩打散规则网格，近岸额外叠加低覆盖细网纹，带宽由低频噪声调制。网纹在世界坐标生成，使用指向湖心 XZ=(0,0) 的径向方向场回溯采样；方向场在湖心平滑归零。`simulation/animated_lake/shaders/foam_flow.wgsl` 在同分辨率网格上沿静态简化速度场用 RK2 积分回溯每套 UV 的周期年龄，发布 RGBA32Float 的两套米制位移；渲染与 SWE 采用相同的“世界坐标减位移”材质采样约定，仅插值湿域供体，避免干域零位移制造岸边剪切。它不是用当前速度乘年龄的一次位移，也不逐帧搬运密度或累计纹理插值误差；轨迹步长按网孔尺度限制，并按 SDF 限制每步回溯长度，避免跨过岩石／岸线。两套 UV 按湖泊绝对模拟时间推进，相位相差半周期，各自的覆盖结果使用 SmoothStep 平滑三角波交叉淡化，复位时对应权重为零；不混合 UV 或距离值。岸边覆盖与接触带仍固定在地形上，波高仅轻微调制带宽；暂停冻结动画，波记录每 256 秒重基准不改变泡沫相位。泡沫以覆盖方式替换局部水面辐射，不作加法发光；诊断视图不显示泡沫。

“湖泊地形”面板提供实时参数：`foam_strength` 为 0～1 的无量纲覆盖强度（0 关闭），`foam_width` 为 0.1～10 米的岸边带宽，`foam_size` 为 0.1～5 米的网孔基础尺寸。均不重置模拟，沿用配置保存规则。旧配置缺字段时强度默认 0、带宽 5 米、网孔 2 米；新湖泊预设强度 0.85。新增 `foam_flow_speed` 为 0～2 米/模拟秒（默认 0.35），`foam_flow_period` 为每套 UV 的 1～20 模拟秒周期（默认 6），缺字段使用默认值。`foam_flow_distortion` 为 0～1 的无量纲近岸速度梯度强度（默认 1），速度以从边界到水内的 SmoothStep 递增，过渡长度取网孔尺寸与两网格间距中的较大者；1 时贴岸慢、离岸快，形成拉伸与剪切，0 时仅保留近似匀速的向心流动和干湿保护。流速 0 时 UV 静止；最大位移不超过流速乘周期。参数实时生效、不重置，但编辑会重新映射当前位移／相位。对同一 SDF 使用两网格间距的中心差分估计梯度，只在流向与 SDF 梯度点积为正、即沿流向距离增大的区域显示泡沫，点积从 0 到 0.35 平滑淡入；因此外岸朝湖内展开，露水岩石迎流侧隐藏，背流侧保留。该方向门控与流速大小独立，不改变底层湖泊波高。该效果没有密度状态、物理输送、绕石流场或历史尾迹，不读取海洋泡沫状态，也不在开阔水面增加淡色网纹。

## 波形与单次反射

- 世界方向角定义相对湖心的扇区，0° 朝 +X、90° 朝 +Z；角度半宽 5～150°，跨 ±180° 连续。波纹中央高度与宽度较大、端部高度平滑归零；端部宽度比例最小 0.05，避免除零。湖心附近平滑淡出方向奇点。
- 每次发射用固定种子的独立通道随机采样方向、角度半宽、传播宽度和近岸起点。`spread_jitter`／`width_jitter` 为基础值的正负比例，范围 0～1、缺字段默认 0.35；最终半宽限制为 5～150°，宽度为 0.005～0.15。`position_jitter` 为无量纲起点正负偏移，范围 0～0.3、缺字段默认 0.04；实际起点限制在 0.005～内侧折返坐标减 0.005。零值关闭对应随机项，不改变其他通道的采样。
- 每次发射冻结方向、角范围、波形、速度和反射参数。入射从实际近岸起点匀速增大传播坐标，到内侧折返坐标反射。反射继承原扇区、粗细及实际起点边界，不把方向角加 180°；仅使传播速度变负，返回近岸方向。
- 抵达内侧折返坐标的事件使用精确模拟时刻，不以发现事件的帧时刻代替。入射在阈值处保持、于交接期淡出；同点生成较弱反射波并淡入，初始高度连续。反射振幅比例 0～0.95，随后按模拟秒半衰期消散，不再反射。
- 结束交接、寿命或传播范围后回收；手动清空、自然过期、场景替换与容量拒绝不产生反射。最终叠加波谷受静水深度约束，干域水面剔除；这是显示限制，不满足体积守恒。

## 时序、容量与命令

CPU f64 时钟按暂停与倍速推进；GPU 时间相对局部原点，每 256 秒同时重基准时间和出生记录。相同输入下，不同正常帧 dt 分割在同一模拟时刻生成一致事件与波位置（数值容差内）。自动出生时刻由节拍原点和整数序号计算；稳定事件顺序与种子决定随机偏差。

总容量 128 条；入射启用反射时预留一个后代名额。满池拒绝新入射并累计丢弃数，不覆盖可见波，不为反射申请额外不可保证的容量。正常运行不从 GPU 回读波列表或模拟场。

- 暂停／倍率零：无自动推进或重复发射；手动发波仍可创建出生记录，淡入与移动等待继续播放。
- 清空：删除活动波和待反射事件，下一次自动发射安排在当前时刻加间隔，不补发旧积压；不重置随机序号或全局时间。
- 应用地形／模式／种子或重新计时：重置波、事件、时钟和随机序列，保留暂停。地形／模式应用不重置相机。
- 编辑发射间隔或启停自动发射：重排下次节拍，不清空旧波。其他发射参数只影响新波及其后代。

## 数据与绘制边界

GPU 单波记录为五个对齐 vec4，共 80 字节。CPU 管理事件／预约，GPU 按时间解析求前沿；先合成最终高度，再从该高度生成坡度，避免并行邻域读写竞争。渲染与支持的光学使用同一发布波场；水面只覆盖本地网格，无无限海洋平铺。

湖泊支持介质消光、手动／天空散射、天空反射与高光、SSR、快速屏幕折射、HDR/Bloom。SSR 用湖波高度筛选水上不透明物体。物理焦散和物理折射保留设置但显式不可用，不编码、不读取原海洋波面，也不自动改成快速模式。海洋的波高增益、水平位移及泡沫快捷设置不影响湖泊；湖泊 FFT 使用自己的叠加强度，沿岸波振幅仍独立。

## UI、保存与失败

六分类 Dock 中，“湖泊地形”面板归场景，保留地形和 FFT 强度；“动画 SDF 波纹”是独立侧边图标入口，包含深度／SDF 模式、波纹种子、发射、波形、反射和诊断。旧布局保留 `lake` 面板位置，新分类缺失时使用默认左右布局，不覆盖其他分类。非湖泊场景的新分类仅显示适用状态，不因导航切换场景。地形和传播场／波纹种子各自编辑草稿、各自显式应用；应用不夹带或丢弃另一面板的草稿，分类切换不重置模拟。发射参数实时影响新波，诊断视图实时切换。提示标注单位、范围与生效语义。共享“波谱与波形”面板在湖泊模式保持可用，编辑草稿后显式应用；湖泊状态隐藏海洋波高增益／挤浪／拓扑控件，禁用远海网格密度，改为同一 FFT 叠加强度控件。其他不可用的海洋业务面板临时隐藏并保留位置；SSR 与波反射分开。

地形／模式构建先验证并建立新资源，成功后替换；校验失败或空水域保留旧资源并显示错误。湖泊设置沿用会话与命名配置的手动保存、只读和 no-settings 规则，不保存草稿、活动波、时间或计数；配置重载从初始波状态开始。旧配置缺少 lake 字段时默认 disabled，不丢弃原参数。

## 验证入口与边界

`cargo test --features ocean --lib` 覆盖配置兼容、确定性地形、独立圆环距离参考、水下岩石、事件分割、单次反射、容量、清空及 egui 模式草稿／显式应用。`ocean --verify-lake` 执行实际 compute／raster、干湿和波谷约束、高度／坡度一致、反射交接、角度跨界／时间重基准、两模式与光学隔离／海洋恢复，检查实际波高能量中心向湖内移动，并用独立解析行进余弦验证 FFT 的世界坐标／周期采样、强度、岸边渐隐开关、最终坡度、暂停与清空／关闭；验证泡沫材质坐标的米制位移与方向、近岸材质间距变化、干湿约束、暂停、帧分割、双相位复位及零流速，并以真实 timestamp 分别测量波场合成与启用泡沫 UV 流动的路径（原程序波基准不含 FFT）；完整 `--verify` 包含这些检查。

离屏快照固定种子／相机／模拟时间，只输出场景，不验证参数面板。真实窗口截图可确认布局可见性，不能单独证明键鼠动作、持久化或动画方向；这些验收状态单独记录在活动变更中。
